BilboMD web tier installed (UI + backend + Mongo + Redis).
  Release:   {{ .Release.Name }}
  Namespace: {{ .Release.Namespace }}

1) Watch the pods come up (expect ui, backend, bilbomd-mongo, bilbomd-redis):
   kubectl get pods -n {{ .Release.Namespace }} -l app.kubernetes.io/instance={{ .Release.Name }} -w

2) When the backend is Ready, view the UI locally:
   kubectl port-forward -n {{ .Release.Namespace }} svc/{{ .Release.Name }} 8080:{{ .Values.ui.service.port }}
   then open http://localhost:8080  (the "configuration data" error should now be gone)

3) Roll back Phase 2 (keep the UI-only state) or remove everything:
   helm rollback {{ .Release.Name }} 1 -n {{ .Release.Namespace }}
   helm uninstall {{ .Release.Name }} -n {{ .Release.Namespace }}
